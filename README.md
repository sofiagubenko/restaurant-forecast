# Програмний комплекс для прогнозування попиту на послуги ресторанів

Бакалаврська робота. Python + Prophet.

## Встановлення

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python app.py
```

## Структура проєкту

- `src/data.py` — модуль підготовки даних
- `src/model.py` — модуль прогнозування
- `src/metrics.py` — модуль метрик
- `app.py` — головний файл
